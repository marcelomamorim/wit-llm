# Segurança

Não inclua chaves, tokens, credenciais de nuvem, dados pessoais ou relatórios confidenciais em issues, pull requests ou exemplos. Para comunicar uma vulnerabilidade, entre em contato com os mantenedores por um canal privado disponível no perfil ou nos mecanismos de reporte privado do GitHub, caso estejam habilitados. Não publique detalhes exploráveis até que os mantenedores possam avaliar o problema.

Se uma credencial tiver sido exposta, revogue-a ou rotacione-a imediatamente no provedor. Remover o valor de um arquivo não o remove dos commits existentes, de clones ou de cópias já publicadas. Revise também logs, artefatos e o histórico Git antes de qualquer publicação.
